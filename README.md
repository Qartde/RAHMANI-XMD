## ⚡ **QUICK START (LOCAL)**

```bash
# 1️⃣ Clone repository
git clone https://github.com/Qartde/RAHMANI-XMD.git
cd RAHMANI-XMD

# 2️⃣ Install dependencies
npm install

# 3️⃣ Configure environment
cp .env.example .env
# Fungua .env na uweke SESSION_ID yako

# 4️⃣ Anzisha bot
npm start
